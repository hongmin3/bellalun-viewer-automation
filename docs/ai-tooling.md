# AI Tooling

## 확인된 현재 설정

- 저장소 내부에 MCP 설정, `.github/workflows/`, Docker/빌드 서비스 설정은 확인되지 않았다.
- 상위 `../.claude/settings.local.json`에는 이 PC에서 사용한 Claude 명령 허용 목록이 있다.
- 이 파일은 사용자별 로컬 권한과 과거 세션 경로를 포함하므로 프로젝트 문서나 Git에 복제하지 않는다.
- `.gitignore`는 자격증명·환경 설정과 런타임 생성물을 이미 분리한다.

## 배치 원칙

- 프로젝트 전용: 이 저장소에만 필요한 MCP, 경로, 최소 권한. 목적과 사용 명령을 여기에 기록한다.
- 글로벌: 여러 저장소에서 공통이고 프로젝트 데이터나 절대경로에 의존하지 않는 도구.
- 제거 후보: 존재하지 않는 임시 scratchpad 경로, 특정 PID, 일회성 진단 명령 같은 로컬 허용 항목.

로컬 허용 목록 정리는 사용자 환경에 영향을 줄 수 있으므로 자동 수행하지 않는다. 새 MCP는 필요 확인 전 추가하지 않는다.

## 탐색 제외 구현

Claude/Codex 모두 `AGENTS.md`의 제외 목록을 따른다. `.gitignore`는 Git 추적용이며 AI 탐색
정책과 별개다. 별도 ignore 설정은 CLI 버전별 지원 여부가 달라 추측성 파일을 만들지 않았다.
지원이 확인된 CLI 버전을 도입할 때 같은 목록을 해당 공식 설정에 옮긴다.
