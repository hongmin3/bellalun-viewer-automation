### 2026-11-05 공유 ZIP의 부분 확인 근거

새 제품 시험을 실행하지 않고 이전 전체 실행의 JSON·HTML·TXT·CSV 4형식 보고서로 확인했다. `work/qa_share_offline_smoke.py`는 네트워크 socket 생성을 차단한 상태에서 `create_package`와 `verify_package`를 수행했다. 결과 기록 `work/공유 검증/한글 공백 오프라인/verification.json`은 `verified=true`, `offline_network_guard=true`, 보고서 4개·자료 파일 121개를 기록한다. 공유 범위는 `evidence=true`, `dicom=false`, `logs=true`다.

생성물은 `work/공유 검증/한글 공백 오프라인/실제 보고서 공유.zip`이며 같은 PC의 하위 `다른 위치에서 풀기` 경로로 추출했다. 추출 파일 122개는 자료 121개와 manifest 1개다. 실측 중 서로 다른 TC가 같은 `01_selected.png` 이름을 사용하는 충돌을 발견해 TDD로 수정했고 공유 단위시험 12개를 통과했다.

추출한 HTML 보고서와 증거 링크는 같은 PC의 별도 Edge 프로필에서 실제로 표시했다. 기록된 조건은 `MAP * ~NOTFOUND`, `disable-background-networking`, 로컬 file URL이다. 같은 ZIP은 후보4 설치 EXE의 검증 CLI도 통과했고 누락·변조·추가 대조군은 모두 거부됐다.

이 결과는 기존 실제 자료를 묶은 로컬 확인이다. 현재 후보의 새 제품 실행 결과, 다른 PC, DICOM 공유는 아직 확인하지 않았다. 현재 후보의 공유 GUI를 통한 생성도 미완료다. 공유 파일과 실제 자료는 로컬 생성물로 보관하고 공개 Git에는 넣지 않는다.

### 제품 실행 전 자원 확인

2026-11-05 앞선 조회에서 VXvue 작업 `#81`의 `completed`와 이동식 USB `VXVUE1`을 확인했지만, 이후 사용자가 현재 VXvue 자동화를 실행 중이라고 명시했다. 현재는 GUI 열기·마우스·키보드·USB 사용을 하지 않는다. 이전 작업 상태 조회를 현재 PC 점유가 없다는 근거로 쓰지 않는다.

사용자의 최신 지시는 실제 UI 회귀를 퇴근 때 별도로 요청하겠다는 것이다. 그 요청 전에는 첫 GUI·UAC·제품 시험을 실행하거나 UI 회귀 승인을 요청하지 않는다. 향후 실제 시작 직전에는 앱 점유와 USB 연결·선택 드라이브를 다시 확인한다.

제품 UI 시험은 [실행 전 승인 절차](testing-guide.md)를 따른다. 최종 EXE·범위·예상 시간·마우스/키보드 점유·DB 복원·설정 변경·USB 범위를 제시하고 답변을 받은 뒤 수행한다. 두 전체가 필요한 변경에서는 약 4시간 예상과 실제 시간을 구분해 남긴다. UAC 승인만으로 이 동의를 대신하지 않는다.

실측 후에는 각 행을 성공/실패/차단으로 바꾸고 날짜·후보 해시·호스트 조건·실행 번호·근거 경로를 기록한다. 수행하지 않은 행은 미완료로 유지한다. 자동 실행 완료와 사람 검수 완료, 배포 게이트 통과는 각각 따로 기록한다.
