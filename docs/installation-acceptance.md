이 표는 설치 성공·프로그램 기동·제품 시험·사람 검수를 따로 기록한다. 기준은 SPEC의 REQ-DIST-001~006, REQ-QA-001~005와 TEST-QA-001~005다.

현재 설치판은 소스173eb3c의1.0.1이다. 2026-11-06 사용자 승인으로 WU 전체만109.3분 실행해 PASS10/SKIP3, WU 범위 게이트14개 통과를 확인했다. 설치 파일1007개와 기존 작업자료364개 보존을 대조했다. 기본기능 전체의 새 실행·UAC 취소·사람 검수·다른OS/계정·제거·다른PC는 미완료다. 아래 후보9 상세는 과거 기록이며 현재 설치판으로 재사용하지 않는다.

### 제품 실행 전 자원 확인

실제 시작 직전에는 다른 자동화·제품의 화면 점유와 USB 연결·선택 드라이브를 다시 확인한다. 이전 작업 상태 조회를 현재 PC 점유가 없다는 근거로 쓰지 않는다. 후보8 실행(2026-11-05 22:47) 직전에는 VXvue 제품과 다른 Bellalun 실행이 없었고 USB `D:`(`VXVUE1`)·`D:\BellalunWU09`를 확인했다.

제품 UI 시험은 [실행 전 승인 절차](testing-guide.md)를 따른다. 최종 EXE·범위·예상 시간·마우스/키보드 점유·DB 복원·설정 변경·USB 범위를 제시하고 답변을 받은 뒤 수행한다. 두 전체가 필요한 변경에서는 약 4시간 예상과 실제 시간을 구분해 남긴다. UAC 승인만으로 이 동의를 대신하지 않는다.

실측 후에는 각 행을 성공/실패/차단으로 바꾸고 날짜·후보 해시·호스트 조건·실행 번호·근거 경로를 기록한다. 수행하지 않은 행은 미완료로 유지한다. 자동 실행 완료와 사람 검수 완료, 배포 게이트 통과는 각각 따로 기록한다.
