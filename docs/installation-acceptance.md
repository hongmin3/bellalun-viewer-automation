# 설치판 인수표

이 표는 설치 성공·프로그램 기동·제품 시험·사람 검수를 따로 기록한다. 기준은 SPEC의 REQ-DIST-001~006, REQ-QA-001~005와 TEST-QA-001~005다.

2026-11-05 문서 작성 시점에는 새 QA 흐름의 소스와 합성 자료 단위시험이 구성되어 있다. 아래 현재 후보 항목의 실제 설치·화면·제품 실행 결과는 아직 이 문서에 수집하지 않았다. `implemented`는 구현 연결을 뜻하며 설치 인수나 제품 검증 완료를 뜻하지 않는다.

## 인수할 후보의 신원

| 항목 | 현재 기록 |
|---|---|
| 소스 commit / dirty 여부 | 최종 후보 빌드 후 기록 필요 |
| Setup 이름·버전·SHA-256 | 미완료 |
| 설치 EXE 경로·SHA-256 | 미완료 |
| build-info 및 assets-manifest 판·해시 | 미완료 |
| 설치한 날짜·OS edition/build·Windows 계정 유형 | 미완료 |
| 승인한 제품 시험 범위·실행 번호·결과·게이트 기록 | 미완료 |

후보가 바뀌면 이 신원과 실측 결과를 같은 후보 기준으로 갱신한다. 이전 인계의 `955dd11` 후보 실측은 과거 후보의 이력이다. 그때의 설치·UAC·기동 결과를 새 QA 흐름이 들어간 현재 후보의 실측으로 재사용하지 않는다. 과거 후보의 원본 인계·해시·결과를 대조하지 않은 항목은 과거 PASS로도 옮겨 적지 않는다.

## 환경별 인수 범위

지원 대상과 실제 측정 결과를 구분한다. 각 행의 설치·실행에는 해당 PC의 제품·SQL·외부 서버 등 선행조건을 준비하고 실제 계정 유형을 기록한다.

| 조건 | 현재 후보 실측 | 과거 근거와 한계 |
|---|---|---|
| Windows 11 Pro x64 | 미완료 | 후보8·10·11의 이전 호스트 실행은 현재 후보 근거가 아니다 |
| Windows 11 IoT Enterprise LTSC x64 | 미완료 | 후보5·6까지만 과거 실행. 후보7 이후 LTSC 미검증 |
| Windows 10 x64 | 미완료 | 기존 기록에도 별도 호스트 실행 없음 |
| 개발 도구 없는 별도 PC 또는 VM | 미완료 | 같은 PC에서 도구를 제외한 최소 환경 실행과 구분 |
| 설치를 시작한 관리자 계정 | 미완료 | UAC 승격 전후와 완료 후 열기 권한을 각각 기록 |
| 표준 사용자 → 다른 관리자 자격증명으로 설치 | 미완료 | 작업 폴더·Windows 사용자·완료 후 실행 계정이 누구인지 확인 필요 |
| 다른 관리자 계정 | 미완료 | 현재 후보의 사용자별 설정·작업 폴더·UAC 확인 필요 |
| 한글 사용자 계정 / 한글·공백 경로 | 미완료 | 경로 단위시험과 실제 계정·설치판 실행을 구분 |

과거 호스트·후보별 상세는 [호환성 기록](compatibility-2026-10-18.md), [이전 최종 검증](handoff-2026-10-18.md)을 참조한다. 이 링크의 성공 결과는 현재 후보의 성공 결과가 아니다. 화면 계약 밖의 해상도·배율은 지원 범위로 확대하지 않고 기존 환경 gate의 차단을 확인한다.

## 설치 수명주기

| 조건 | 확인할 결과 | 현재 후보 실측 |
|---|---|---|
| 새 설치 | 관리자 확인, 파일 배치, 바로가기·PATH·App Paths 등록, 제품 시험 자동 시작 없음 | 미완료 |
| 설치 UAC 취소 | 설치 미수행, 오해 없는 종료·안내 | 미완료 |
| 완료 후 열기 | 원래 사용자의 일반 권한으로 GUI 시작. 관리자로 먼저 시작한 Setup도 별도 측정 | 미완료 |
| 시작 메뉴·바탕화면·직접 실행 | 같은 설치 EXE·작업 폴더·설정 사용 | 미완료 |
| 새 CMD·PowerShell·Win+R / 다른 CWD | 명령 검색과 출력·종료 코드 정상, 작업 경로 유지 | 미완료 |
| 기존 판 위 업데이트 | 같은 AppId·위치, resources 교체, 새 EXE 해시 일치 | 미완료 |
| 업데이트 자료 보존 | 작업의 config·Reports·Evidence·Log·Runs·review 기록 보존. 전후 파일 목록·해시 대조 | 미완료 |
| 제거 | 설치기가 추가한 PATH만 제거, 다른 PATH 보존, 작업 자료 보존 | 미완료 |
| 제거 후 재설치 | 보존 자료 재사용, 오래된 보고서를 새 실행 결과로 연결하지 않음 | 미완료 |
| 다른 드라이브·한글·공백 설치/작업 경로 | 권한·경로·새 셸 실행 확인 | 미완료 |

자료 보존은 시험용 사본으로 전후 파일 목록과 해시를 비교한다. 설치기 성공 코드나 파일 개수만으로 보존 성공을 기록하지 않는다. 실제 설정·환자 자료·사내 Baseline은 공개 증거에 넣지 않는다.

## 첫 사용자 QA 흐름

| 조건 | 확인할 결과 | 현재 후보 실측 |
|---|---|---|
| 준비 실패 해결 | 실패 행의 현재 상태·해결 방법, 해당 설정 열기, 사람이 수정 후 다시 점검. 기존 gate 유지 | 미완료 |
| 두 전체 실행의 동의 화면 | Viewer·SQL·DB 4개·Baseline 판/날짜/해시, 변경·복구 정책. 직접 체크 전 시작 금지 | 미완료 |
| 동의 화면 취소 | 자식 시험 미시작, DB·제품 변경 없음 | 미완료 |
| 동의 후 시험 UAC 취소 | 종료 1223, UAC 취소 상태와 미실행 안내 | 미완료 |
| 진행·중단 | 이번 run_id의 TC·완료/전체·경과 시간·중단 요청, 중단 상태와 보고서 연결 | 미완료 |
| worker 오류 / GUI 강제종료·재시작 | 비정상·미완료를 완료로 오인하지 않음. 이전 실행과 결과 분리 | 미완료 |
| 정상 종료 | 이번 실행의 새 보고서만 연결, 결론·다음 행동·미수행 범위 표시 | 미완료 |
| 사람 검토 | PASS 아닌 TC 모두 기록·검토자 필수, 의견·결함 번호 재열기, 자동 결과 보존 | 미완료 |
| 공유 범위 | 선택한 보고서·검토 기록과 명시적으로 선택한 증거만 포함, 설정·비밀번호 제외 | 미완료 |
| 다른 PC 오프라인 ZIP | 한글·공백 경로에 풀어 HTML·증거 링크 열기. manifest·누락·추가·변조 검증 | 미완료 |
| 직접 CLI 전체 실행 | 화면 동의 없음(CLI) 기록, 기존 엔진 진입과 환경 gate 유지 | 미완료 |

제품 UI 시험은 [실행 전 승인 절차](testing-guide.md)를 따른다. 최종 EXE·범위·예상 시간·마우스/키보드 점유·DB 복원·설정 변경·USB 범위를 제시하고 답변을 받은 뒤 수행한다. 두 전체가 필요한 변경에서는 약 4시간 예상과 실제 시간을 구분해 남긴다. UAC 승인만으로 이 동의를 대신하지 않는다.

실측 후에는 각 행을 성공/실패/차단으로 바꾸고 날짜·후보 해시·호스트 조건·실행 번호·근거 경로를 기록한다. 수행하지 않은 행은 미완료로 유지한다. 자동 실행 완료와 사람 검수 완료, 배포 게이트 통과는 각각 따로 기록한다.
