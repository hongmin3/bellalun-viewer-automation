## 4. 고정 대기와 Viewer 재시작 (코드 정적 분석)

실행 기록에는 대기 시간만 따로 남지 않는다. 아래는 코드에서 센 추정이다.

| 항목 | 위치 | 회당 고정 대기 |
|---|---|---|

| 검사 닫기 `flows.close_examine` | WF01~15·XIPL 여러 곳 | 1.5 + 6~10초 |
| 설정 그룹 이동 `flows.open_group_page` | WF14 목록 수집 19페이지 × 2회 | 약 5초(그룹을 매번 다시 누름) |
