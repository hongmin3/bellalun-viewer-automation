BellalunAuto — 팀원 사용 안내

1. BellalunAuto-<버전>-setup.exe를 관리자 권한으로 설치합니다.
   설치 폴더는 다른 드라이브나 한글/공백이 있는 경로를 선택할 수 있습니다.
2. 시작 메뉴의 BellalunAuto를 실행하고 쓰기 가능한 작업 폴더를 선택합니다.
   작업 폴더는 설치 폴더 밖에 두십시오. 설정·Reports·Evidence는 이곳에 저장됩니다.
3. 설정 화면에서 이 PC의 Viewer/SQL/서버/OCR/승인 자료 경로를 확인하고 저장합니다.
   기본 템플릿의 예시값은 이 PC에 맞게 입력해야 합니다.
4. 자체진단과 환경 점검을 먼저 수행한 후 기본기능 전체 또는 Windows Update 전체를 실행합니다.
   전체 실행은 실제 제품과 DB 상태를 변경할 수 있으므로 전용 QA 환경을 사용합니다.
5. 결과 폴더에서 리포트와 증거를 확인합니다. FAIL·MANUAL·SKIP은 PASS와 구분합니다.

새 PowerShell/CMD에서 BellalunAuto --version, Win+R에서 BellalunAuto를 사용할 수 있습니다.
설치 직후 이미 열려 있던 셸은 닫고 다시 여십시오.
관리자 권한이 필요한 실행은 UAC 승인을 요청하며 취소하면 실행을 중단합니다.
설치 프로그램은 제품 시험을 자동으로 시작하지 않습니다.
업데이트/제거 시 외부 작업 폴더의 설정·결과·증거를 보존합니다.
제거 프로그램은 설치 프로그램이 추가한 PATH 항목만 제거합니다.

Python·Git·개발 소스는 팀원 PC의 필수 준비물이 아닙니다.
Bellalun Viewer/SQL Server/Tesseract OCR 및 해당 시험의 외부 서버·USB는 별도 준비합니다.
제품 시험 범위와 실제 검증 환경은 배포 담당자의 검증 기록을 확인하십시오.

내부 체크리스트·사양/매뉴얼·승인 Baseline이 포함되어 있습니다.
본 설치 파일과 포터블 ZIP을 공개 저장소·공개 Release에 업로드하지 마십시오.
